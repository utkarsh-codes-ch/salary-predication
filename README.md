# Employee Salary Prediction

Predicts an employee's annual salary (in LPA) using XGBoost. Web app built with Streamlit.

## Run locally
```
pip install -r requirements.txt
streamlit run salary_prediction.py
```

## Files
- `salary_prediction.ipynb` - cleaning, analysis and model training
- `salary_prediction.py` - Streamlit app
- `salary_model.json`, `salary_model.pkl` - trained model
- `employee_salary_dataset.csv` - dataset
- `Project_Document.pdf` - project report
